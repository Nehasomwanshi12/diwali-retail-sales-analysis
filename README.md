# Diwali Retail Sales Analysis | Power BI Dashboard

## Project Overview
An interactive Power BI dashboard developed to analyse Diwali retail sales performance and present key business insights through data visualisation.

The dashboard helps explore revenue, delivered orders, customers, estimated profit, return rate, regional performance, product categories and order status.

## Tools & Technologies
- Power BI Desktop
- Power Query – data cleaning and transformation
- DAX – calculated measures and calendar table
- CSV – source data

## Dashboard Features
- KPI cards: Total Revenue, Delivered Orders, Estimated Profit, Total Customers and Return Rate
- Monthly Revenue Trend
- Regional Sales Performance
- Revenue by Product Category
- Order Status Distribution
- Interactive Year, Region and Category slicers

## Business Questions
1. What is the overall revenue generated?
2. Which region contributes the highest revenue?
3. Which product categories generate the most sales?
4. How does revenue change over time?
5. What is the distribution of orders by status?

## Key Metrics
- Total Revenue: ₹5.19 Cr
- Delivered Orders: 26.94K
- Estimated Profit: ₹1.67 Cr
